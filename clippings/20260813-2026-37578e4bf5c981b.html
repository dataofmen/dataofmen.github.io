Title: 클로드 코드 가이드 (2026)

채팅까진 그냥 똑똑한 챗봇. 내 삶이 바뀐 건 — 클로드 코드 켜고 나서부터야.

이 가이드는 Cowork 빼고, 클로드 코드 하나에만 집중한다.

클로드 채팅 = 웹·앱에서 말 거는 AI. 물어보면 답을 줘.

클로드 코드 = 그 AI를 내 컴퓨터 안에 들여놓은 거. 내 파일을 직접 열고, 고치고, 만들고, 명령까지 실행 해.

까만 터미널 창에서 돈다고 겁먹지 마. 코딩하는 게 아니라 한국어로 일을 시키는 거야. 코드는 걔가 짠다.

클로드 채팅클로드 코드
파일을 하나씩 복붙해야 함폴더째 통째로 읽음
결과가 채팅 안에만 남음진짜 내 파일을 직접 만들고 고침
긴 작업을 혼자 못 끝냄몇 시간짜리도 혼자 돌림
매번 처음부터 설명한 번 세팅하면 기억(CLAUDE.md)

한 줄 요약: 채팅은 물어보는 곳, 코드는 일 시키는 곳.

유료 플랜 — 무료 클로드론 안 됨. Pro($20)부터 / Max / Team

Claude 데스크탑 앱 — 이게 다야. Node·터미널 설치 필요 없음.

이 가이드는 제일 쉬운 길 = 데스크탑 앱 기준이야. 터미널·VS Code·npm 설치(개발자용)는 “완전 정복 가이드”에서 따로 다뤄.

꼭 공식 주소에서만. 다른 사이트·토렌트로 받지 마.

앱 열고 로그인 — Mac은 응용 프로그램, Windows는 시작 메뉴에서 Claude 실행 → 내 계정으로 로그인 (Pro 이상)

“Code” 탭 열기 — 앱 상단 가운데 Code 탭 클릭. 클로드 코드가 여기 들어있어 — Node·CLI 따로 설치 안 해도 됨.

작업 폴더 선택 — 작업할 폴더 하나 고르기 (이 폴더가 클로드의 작업 공간이 돼)

한국어로 말 걸기 — “이 폴더에 뭐 있어?” / “오늘 날짜 뭐야?” 쳐보면 작동 확인

까만 터미널 창? 안 열어도 돼. 앱 안에서 채팅하듯 한국어로 시키면 끝.

클로드 코드는 매번 “내가 누구냐면…” 설명하면 너무 비효율적이야. 정보를 파일로 박아두면 알아서 읽어.

파일역할읽는 방식
CLAUDE.md일하는 규칙매 세션 자동으로 먼저 읽음
about-me.md내가 누군지CLAUDE.md가 “참고해”로 연결
voice.md내 말투·톤글 쓸 때 참고

작업 규칙## 시작 전 항상- about-me.md 와 voice.md 를 먼저 읽어라. - 바로 실행하지 말고, 불명확하면 먼저 질문해라. 결과물- 문서·콘텐츠는 한국어로. 웹은 HTML 한 파일로. - 항상 내가 바로 쓸 수 있는 완성형으로. 하지 말 것- 내 허락 없이 파일 삭제 금지. - “할 수 있습니다” 같은 늘어지는 AI 말투 금지.

​

직접 빈칸 채우기 어렵지? 클로드한테 인터뷰를 시켜. 한 번에 하나씩 물어보고, 답하면 알아서

about-me.md

랑

voice.md

로 정리해줘.

앱에서 작업 폴더 열고, 아래를 그대로 붙여넣기:

나에 대한 about-me.md 와 voice.md 를 만들고 싶어. 네가 인터뷰어가 되어서 아래 질문을 한 번에 하나씩만 물어봐. 내가 답하면 다음 질문으로 넘어가. 7개 다 끝나면 요약 보여주고, 확인받은 다음에 about-me.md 와 voice.md 두 파일로 저장해. 질문: 1. 무슨 일을 해? (직업 / 전문 분야 한 줄) 2. 주요 고객이나 타깃 독자는 누구야? 3. 주로 어떤 결과물을 만들어? (콘텐츠 / 웹 / 자동화 등) 4. 어떤 말투를 원해? (격식체 / 친근체 / 직접적 / cold·confident 등) 5. 절대 쓰기 싫은 표현·단어가 있어? (예: “정말”, “너무”, “함께”) 6. 네가 잘 썼다고 생각하는 글·작업 하나 통째로 붙여줄게. (붙여넣기) 7. 클로드가 항상 지켜야 할 규칙 1~2개는?

​

→ 클로드가 질문을 하나씩 던지고, 마지막에 두 파일을 폴더에 만들어줘. 이게 5분 만에 about-me 끝내는 법.

6번이 제일 강력해. 지시 백 줄보다 잘 된 글 원문 하나 가 내 톤을 더 잘 가르쳐.

파일 다 만들었으면:

CLAUDE.md, about-me.md, voice.md 다 읽고 내 정보랑 규칙을 한 번 요약해서 확인시켜줘. 틀린 거 있으면 어디 고치면 되는지 알려줘.

틀린 부분 한 줄로 고쳐주면 끝. 이게 클로드를 길들이는 법이야.

익숙해지면 메모리 파일 하나로 “기억하는 비서”를 만들 수 있어.

/sync (낮) — 메모·회의록 처리하고 할 일 업데이트

처음엔 건너뛰어도 돼. CLAUDE.md + about-me만으로도 충분히 강해.

랜딩 한 장 — “내 소개 랜딩페이지 HTML 한 파일로”

첫 스킬 굳히기 — 제일 잘 된 작업 골라 스킬로 (아래 “첫 스킬 직접 만들기” 참고)

1번이 핵심 파일을, 5번이 첫 스킬을 만들어줘. 한 바퀴 돌면 시스템 완성.

스킬 = 클로드한테 미리 가르쳐둔 “전문 기술” 하나. 한 번 잘 통한 작업 방식(또는 남이 만든 노하우)을 파일로 저장해두는 거야.

쉽게: 매번 “이렇게 저렇게 해줘”라고 설명하는 대신, 그 설명을 한 번 적어서 이름표를 붙여둔 것. 다음부턴 이름만 부르면 클로드가 그대로 일해.

자동 발동: 내가 관련된 부탁을 하면 클로드가 “어, 이거 그 스킬 쓰면 되겠다” 하고 알아서 켜. (그래서 설명문을 잘 써야 해 — 맨 아래에서 다룸)

두 가지 출처: ① 남이 잘 만든 스킬 깔기 (바로 아래 9개) ② 내가 직접 만들기 (맨 아래 “첫 스킬 직접 만들기”)

모양: 폴더 하나 + 그 안에

SKILL.md

파일 하나. 그게 전부야.

앱·플러그인이 아니라 그냥 텍스트 파일 이야. 그래서 누구나 만들고, 공유하고, 깔 수 있어.

기초가 익으면, 매번 프롬프트 새로 쓰지 말고 스킬 을 깔아. 수백 개 중 크리에이터·PM이 진짜 제일 많이 쓰는 것만 추렸어:
